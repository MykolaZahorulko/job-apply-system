# Profile interview guide

Goal: fill `workspace/02-profile/master-profile.md`. One section at a time, short questions, confirm before moving on. Adapt wording to the user's field (no IT assumptions).

## If an old CV exists
Parse it, fill the profile, show a summary, ask ONLY about gaps and thin bullets. Also run an **honesty check**: ask if any role, date, or metric was padded or invented (by the user or a previous AI tool). Drop anything unverified and replace padded filler with deeper detail on real projects from the actual job(s).

## Order (also used when starting completely from scratch)
1. Basics: full name, location, contacts, work authorization, relocation, notice period.
2. Target: roles, industries, locations/remote, salary expectation (optional).
3. Experience (each role, newest first): title, company, dates, location, scope (team/budget/clients/volume), responsibilities, tools.
4. For each role dig for achievements: "What changed because of you? Numbers (%, money, time, volume, people)? What did you do exactly vs the team? Any recognition?" Help turn vague duties into action+method+result bullets. If no numbers exist, use qualitative scale/scope; never invent figures - mark estimates as "approx." only if the user confirms.
5. Projects (incl. academic, volunteer, freelance, personal): goal, role, actions, result, tools, link.
6. Skills: hard skills with level, tools, soft skills only with evidence.
7. Education, certifications, courses, languages (with level), awards/publications.
8. Exclusions: anything not to show (old jobs, gaps, personal details).

## Output
Write facts in `workspace/02-profile/master-profile.md` with an achievement bank (8-20 bullets per major role, tagged by theme, e.g. [leadership], [analytics]). Read the summary back to the user and ask for corrections.
